# 부스 배치도 플래너

전시 부스 안팎의 배치도를 그리는 2D 평면도 편집기입니다. 설치·서버 없이 `index.html` 을 열면 바로 동작합니다.

## 실행

| 환경 | 방법 |
| --- | --- |
| Windows | `부스배치도.bat` 더블클릭. 바탕화면 바로가기가 필요하면 `make-shortcut.ps1` 우클릭 → PowerShell 로 실행 |
| macOS | `부스배치도.command` 더블클릭 (최초 1회는 우클릭 → 열기) |
| Linux | `부스배치도.desktop` 에 실행 권한을 주고 더블클릭 |
| 공통 | `index.html` 을 브라우저(Chrome/Edge/Firefox/Safari)로 열기 |

## 기능

- **부스(기준 구역)** 이름·너비·깊이를 실측으로 입력. 단위 cm / mm / m 전환.
- **집기 라이브러리** 책상·의자·회의 테이블·카운터·파티션·배너·모니터 등 15종 원클릭 추가.
- **도형 7종** 사각형 / 둥근 사각형 / 원·타원 / 삼각형 / 마름모 / 반원 / 구역(점선). 선택 후 언제든 모양 변경.
- **속성 편집** 이름, 너비, 깊이, 위치, 회전, 색상, 메모, 치수 표시, 잠금. 여러 개 선택 시 동시 편집.
- **조작** 드래그 이동, 8방향 크기 조절 핸들, 회전 핸들(15° 스냅), 격자 스냅, 복제, 삭제, 맨 앞/뒤, 실행 취소/다시 실행.
- **파일** JSON 저장·불러오기, PNG / SVG 내보내기, 인쇄(PDF), 브라우저 자동 저장.
- **테마** 블루프린트 / 페이퍼 / 스튜디오.
- **업데이트 확인** GitHub 릴리즈에서 새 버전을 확인하고 다운로드 (하루 1회 자동 확인, 실패해도 앱 사용에 영향 없음).

## 단축키

앱 우상단 `?` 버튼에서 전체 목록을 볼 수 있습니다. 주요 키: `Ctrl+Z/Y` 실행 취소/다시 실행, `Ctrl+D` 복제, `Delete` 삭제, `R` 90° 회전, 방향키 이동, `Shift+클릭` 다중 선택, `Shift+빈 곳 드래그` 영역 선택, 휠 확대/축소.

## 업데이트 적용

"업데이트 확인" → 새 버전이 있으면 zip 을 내려받아 압축을 풀고, 이 폴더에 덮어쓰면 됩니다. 브라우저에 자동 저장된 배치도는 유지됩니다.

## 파일 구성

`index.html`, `app.css`, `app.js`, `version.json`, `icon.svg`, 실행 바로가기 3종, `make-shortcut.ps1`, `HANDOFF.md`(개발 인계 문서), `style-candidates/`(UI 스타일 미리보기).
