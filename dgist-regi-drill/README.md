# 수강신청 연습 시뮬레이터 (DGIST)

DGIST 수강신청(sugang.dgist.ac.kr)의 **진행 흐름을 본떠 만든 오프라인 연습 도구**입니다.
실제 서버에 어떤 요청도 보내지 않고, 학번·비밀번호를 받지 않으며, 실제 수강신청을 대신 하지 않습니다.
과목코드 입력·클릭 속도와, 실패했을 때 대체 과목으로 갈아타는 **판단 속도**를 반복 훈련하고 기록으로 측정하는 것이 목적입니다.

> ⚠️ 이 프로그램은 매크로·자동신청 도구가 아닙니다. 실제 사이트를 자동 조작하거나 봇 차단을 우회하지 않습니다.
> 대부분의 대학이 매크로 사용을 수강신청 무효·학사징계 사유로 규정합니다. 이 도구는 **사람이 직접 하는 연습**만 돕습니다.

---

## 실행 방법 (로컬 서버 불필요)

`app.html` 을 브라우저로 열기만 하면 됩니다. 설치도, 서버도 필요 없습니다.

### 원클릭 바로가기
- **Windows**: `shortcuts/Windows_바로가기_만들기.vbs` 더블클릭 → 바탕화면에 아이콘 바로가기 생성
- **macOS**: `shortcuts/macOS_실행.command` 더블클릭 (막히면 우클릭 → 열기)
- **Linux**: `bash shortcuts/Linux_바로가기_만들기.sh` → 바탕화면에 `.desktop` 바로가기 생성

바로가기를 만들지 않아도 `app.html` 을 직접 더블클릭하면 실행됩니다.

## 사용법

1. **① 준비**
   - 노리는 과목을 **신청 목록**에 넣습니다. (▲▼로 우선순위 조정, 위쪽이 먼저 잡을 과목)
   - **경쟁도**: 그 과목이 얼마나 빨리 마감되는지(100=약 1초 만에 마감, 0=마감 안 됨).
   - **훈련 설정**: 쉬움/보통/실전 프리셋 또는 직접 설정. 입력 방식(직접 입력·목록 클릭·혼합),
     목표 학점, 카운트다운, 서버 지연, 확인 팝업, 보안문자, 오픈 시각 오차, 돌발 오류.
   - `학점 직접입력` 표시가 붙은 과목(예: Capstone)은 신청할 때 학점을 직접 넣습니다. (DGIST 특성 반영)
2. **② 훈련**
   - 카운트다운이 끝나면 신청이 열립니다. **열리기 전에 누르면** 실전처럼 오류가 나고 실수로 기록됩니다.
   - 여석은 시간이 지나면 줄어들다가 0이 되면 마감됩니다. 경쟁도가 높은 과목부터 빠르게 잡으세요.
   - 실패(정원 초과·시간표 중복 등)가 나면 **대체 과목으로 즉시 전환**하는 연습을 하세요.
3. **③ 결과**
   - 총 소요 시간, 구간별 랩타임, **서버 지연을 제외한 내 조작 시간**, 실수, 직전 기록 대비, 코칭을 봅니다.
   - 지난 훈련 기록(최근 20회)이 함께 보관됩니다. 같은 조건으로 다시 돌려 기록을 안정시키세요.

### 실전 팁
- 실제 DGIST 수강신청은 **서버 시각**이 중요합니다. 네이비즘·포이타임 등에서 `sugang.dgist.ac.kr`
  서버 시각을 확인하고 **정각**에 신청하세요. 이 앱의 카운트다운은 그 감각을 연습하기 위한 것입니다.
- 미리 로그인해 두고, 과목코드를 손에 익혀 두면 실전에서 망설이는 시간이 줄어듭니다.

## 업데이트

- 앱 하단의 **[업데이트 확인]** 버튼으로 GitHub 최신 릴리즈를 확인합니다. (공개 API만 사용, 로그인 불필요)
- 새 버전이 있으면 변경 내역을 보여주고, 승인하면 새 `app.html` 을 내려받습니다.
  브라우저는 보안상 로컬 파일을 직접 덮어쓸 수 없으므로, 내려받은 파일로 기존 `app.html` 을 교체해 주세요.
- 네트워크가 없거나 GitHub에 접근할 수 없어도 **앱은 그대로 사용**할 수 있습니다.
- "실행 시 자동 확인"을 켜두면 열 때마다 조용히 확인합니다(실패해도 방해하지 않음).

## 개인정보 · 보안

- 학번·비밀번호·이름을 **입력받지도, 저장하지도** 않습니다.
- 과목 목록·설정·기록은 브라우저의 `localStorage`(이 기기)에만 저장됩니다.
- 외부 통신은 **업데이트 확인(GitHub 공개 API/raw)** 이 유일하며, 그 외 어떤 서버로도 데이터를 보내지 않습니다.
- 토큰·자격 증명을 코드에 넣지 않았습니다.
