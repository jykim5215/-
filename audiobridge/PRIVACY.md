# AudioBridge 개인정보처리방침

시행일: 2026-07-13

AudioBridge(이하 "앱")는 같은 Wi-Fi/LAN에 있는 기기 사이에서만 소리를 전송하는 앱입니다.

## 수집하는 정보

**앱은 어떠한 개인정보도 수집·저장·전송하지 않습니다.**

- 앱에는 서버가 없습니다. 모든 통신(기기 검색, 연결, 오디오)은 사용자의 로컬 네트워크
  안에서 기기 간에 직접 이루어지며, 외부 인터넷으로 전송되지 않습니다.
- 업데이트 확인 시 GitHub 릴리스에서 버전 정보 파일을 내려받는 요청만 발생하며,
  이 요청에 개인정보가 포함되지 않습니다.

## 권한 사용 목적

| 권한 | 목적 |
|---|---|
| 마이크(RECORD_AUDIO) | 사용자가 "마이크" 소스를 선택했을 때, 소리를 페어링된 상대 기기로 실시간 전송하기 위해서만 사용. 녹음 파일을 만들거나 저장하지 않음 |
| 미디어 프로젝션(화면 소리 공유) | 사용자가 "미디어 소리" 소스를 선택했을 때, 재생 중인 앱 소리를 상대 기기로 전송하기 위해서만 사용. 화면 영상은 캡처하지 않음 |
| 알림 | 스트리밍 동작 상태 표시 |

오디오는 상대 기기로 전송되어 재생된 뒤 즉시 폐기되며, 어디에도 저장되지 않습니다.
