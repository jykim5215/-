# AudioBridge — 폰 ↔ 폰 · 폰 ↔ PC 오디오 스트리밍

같은 Wi-Fi/LAN에 있는 기기들이 **서로의 스피커가 되어 주는** 저지연 스트리밍 앱.
**폰끼리도**(한 폰이 다른 폰의 스피커), 폰↔윈도우 PC도 됩니다.
블루투스를 쓰지 않고 네트워크 소켓(UDP 기본, TCP 옵션)으로 동작합니다.

| 구성 요소 | 파일 | 요구 사항 |
|---|---|---|
| 안드로이드 앱 | `AudioBridge.apk` | Android 8.0(API 26) 이상 · 내부 소리 캡처는 Android 10+ |
| 윈도우 프로그램 | `AudioBridgeWin.exe` | Windows 10/11 x64 (단일 실행파일, 설치 불필요) |

## 1. 설치

**폰:** `AudioBridge.apk`를 폰으로 옮겨 설치합니다. "출처를 알 수 없는 앱" 허용이 필요할 수 있습니다.
설치하면 런처에 **AudioBridge 아이콘**(스피커+양방향 화살표)이 생기고, 누르면 바로 실행됩니다.

**PC:** `AudioBridgeWin.exe`를 아무 폴더에 두고 더블클릭하면 끝입니다. Windows 화면은 Android와
같은 전용 스피커 아이콘과 둥근 카드 스타일을 쓰되, 연결 상태·PC 이름·업데이트만 간결하게 표시합니다.
- 처음 실행 시 **Windows 방화벽 허용 창**이 뜨면 반드시 **개인 네트워크 허용**을 체크하세요.
- 바탕화면 바로가기를 만들어 두면 원클릭으로 실행할 수 있습니다 (exe 우클릭 → 보내기 → 바탕 화면에 바로 가기 만들기).

## 2. 사용법 — 연결하고, 소리 나올 곳만 고르면 끝

1. **연결하기**
   - 폰↔폰: 두 폰 모두 앱을 열어 두고, 한쪽에서 **기기 찾기** → 상대 이름 선택.
   - 폰↔PC: PC에서 `AudioBridgeWin.exe` 실행 후 폰에서 **기기 찾기**.
   - 안 보이면 **IP 주소로 직접 연결** (PC IP는 `cmd` → `ipconfig`).
   - **공유기가 없을 때 (Wi-Fi Direct):** 연결 카드 아래 **"Wi-Fi Direct로 연결"** → 주변 폰
     선택. 같은 Wi-Fi가 없어도 폰끼리 바로 붙습니다(블루투스처럼 켜고 페어링하는 느낌).
     처음 한 번 "주변 기기" 권한을 허용하세요. 연결되면 소리·동기·다대일은 Wi-Fi와 동일하게
     동작합니다. (폰↔폰 전용 기능이며, 한쪽이 그룹장이 되어 상대가 붙는 구조입니다.)
2. **소리가 나오는 곳 고르기** — 연결되면 두 버튼이 보입니다: **[이 기기] [상대 기기]**
   - 폰↔폰: **양쪽이 서로 반대로 고르면**(한쪽 "이 기기", 다른 쪽 "상대 기기") 그때 소리가 흐릅니다.
     한쪽이 스피커, 다른 쪽이 소스가 되는 방식이라 서로 동의해야 시작돼요.
   - 폰↔PC: PC는 자동으로 동의하므로 폰에서 고르는 즉시 시작됩니다.
3. **보낼 소리 고르기** — "상대 기기"를 고른 쪽에 선택지가 나옵니다:
   - **미디어 소리**: 음악·게임 소리 (Android 10+, 일부 앱은 보호 때문에 무음)
   - **마이크**: 주변 소리를 그대로 — 한 폰이 마이크, 다른 폰이 확성기가 됩니다.

그 외에는 자동입니다: 연결이 끊기면 스스로 다시 연결하고, PC와 연결하면 지난번 선택을 기억해 바로 재생합니다.
새 버전이 나오면 Android와 Windows 모두 위쪽 배너에서 버튼 한 번으로 업데이트됩니다. 내려받은 파일은
릴리스의 SHA-256 값과 일치하는지 확인한 뒤에만 설치/교체합니다.

### 스피커 여러 대 (다대일)

"상대 기기"를 골라 보내는 중이면 **"+ 스피커 추가"** 버튼으로 스피커를 최대 4대까지 붙일 수 있습니다
(폰·PC 혼합 가능). 모든 스피커는 시계를 맞춰 **같은 시점에** 소리를 냅니다.
AudioBridge는 각 기기의 공통 시계뿐 아니라 Android의 실제 하드웨어 출력 시각과 Windows의 WASAPI
재생 헤드까지 확인해 **샘플 단위로** 같은 순간을 목표로 합니다.

**지연은 자동으로 가장 짧게** 맞춥니다: 스피커들이 실제로 잰 Wi-Fi 지연과 출력 버퍼를 보고해 오고,
소스 폰이 끊기지 않는 가장 짧은 공통 지연을 고릅니다(좋은 5GHz 공유기 약 100ms, 보통 가정 Wi-Fi 약 150–200ms).
설정에서 **공통 지연 자동**을 끄면 40–2000ms를 직접 고를 수 있고, 소리가 흐르는 중에도 바뀝니다.
근거와 한계는 [`LATENCY_POLICY.md`](LATENCY_POLICY.md)에 있습니다.
소스 기기에서 다른 앱이 직접 내는 원음은 AudioBridge가 늦출 수 없으므로, 네트워크 스피커와 함께
들을 때는 **소스 기기를 음소거하고 연결된 스피커만 사용**하는 것이 가장 정확합니다.

- **스피커별 볼륨**: 각 스피커 줄의 슬라이더로 소스 폰에서 바로 조절합니다 (0 = 음소거).
- **스테레오 페어**: 스피커 줄의 채널 칩을 눌러 **양쪽 → 왼쪽 → 오른쪽**으로 바꿉니다.
  폰 두 대를 왼쪽/오른쪽으로 지정하면 진짜 스테레오 스피커 세트가 됩니다 (미디어 소리 전송 시).

### 스피커 소리 맞추기 (기기를 붙여 놓고)

스피커마다 내부 처리 지연(DSP)이 달라서 OS가 모르는 차이가 수 ms 남을 수 있습니다. 두 대 이상에 보내는 중이면
스피커 목록 아래 **스피커 소리 맞추기**를 누르세요.

1. 모든 스피커를 소스 폰 옆에 **같은 거리로** 모아 두고 볼륨을 올립니다 (조용한 곳).
2. 음악이 잠시 멈추고 스피커마다 짧은 시험음이 차례로 3번씩 납니다 — 음악과 똑같은 재생 경로로.
3. 소스 폰 마이크로 들은 도착 시각 차이만큼 빠른 스피커를 늦춰 저장합니다. 끝나면 음악이 다시 나옵니다.

맞춘 값은 각 스피커의 설정에 "스피커 소리 맞추기 보정 +x.xms"로 보이고 초기화할 수 있습니다.
그래도 어긋나 들리면 빠른 쪽 기기의 **이 기기 추가 지연**(+0~300ms)으로 더 늦출 수 있습니다.
- 소음이나 반향 때문에 감지에 실패하면 기존 수동 설정값을 그대로 유지합니다.

## 3. 내 기기 이름

앱 이름 아래 표시되는 기기 이름을 누르면 바꿀 수 있습니다(설정). 기본은 폰 모델명이고,
바꾼 이름이 상대 기기의 검색 목록에 그대로 보입니다.

## 4. 설정 (⚙)

| 항목 | 설명 |
|---|---|
| 공통 지연 자동 | 기본 켜짐. 끊기지 않는 가장 짧은 공통 지연을 스스로 고름 ("지금 ○○ms"). 끄면 40–2000ms 직접 선택 |
| 스피커 소리 맞추기 보정 | 스피커 소리 맞추기로 정해진 이 기기의 추가 지연 표시·초기화 |
| 이 기기 추가 지연 | 0~300ms. 더 빠르게 들리는 수신기만 늦추는 단방향 보정 |
| 연결 방식 | 기본 "빠름". Wi-Fi가 많이 불안하면 "안정"으로 |
| 업데이트 확인 | 새 버전 수동 확인 |

## 5. 포트 안내 (방화벽)

| 용도 | 프로토콜/포트 | 방향 |
|---|---|---|
| 컨트롤 | TCP 48550 | 폰 → PC |
| 자동 검색 | UDP 48551 | 폰 → PC (브로드캐스트) |
| 모드 A 오디오 | UDP 48552 | PC → 폰 (TCP 모드에선 폰 → PC 48552) |
| 모드 B 오디오 | UDP 48553 | 폰 → PC (TCP 모드도 동일 포트) |

PC 포트 변경: `AudioBridgeWin.exe --ctl-port=48550 --mode-a-port=48552 --mode-b-port=48553 --name=표시이름`

## 6. 문제 해결

| 증상 | 확인 |
|---|---|
| PC가 검색되지 않음 | 같은 Wi-Fi인지 · PC 프로그램 실행 중인지 · 방화벽에서 허용했는지 · 공유기 "AP 격리" 꺼짐 확인. 수동 IP 입력으로 우회 가능 |
| 연결은 되는데 소리가 안 남 | 방화벽에서 UDP 차단 여부 확인 → 고급 설정에서 TCP로 전환해 테스트 |
| 소리가 끊김 | 5GHz Wi-Fi 사용 · 공유기 근처로 이동 · 연결 방식을 "안정"으로 변경 |
| "포트 사용 중" 오류 | 이전 인스턴스가 떠 있는지 확인 후 종료, 또는 포트 옵션으로 변경 |
| 내부 소리 캡처가 무음 | 해당 앱이 캡처를 차단(DRM) — 마이크 소스로 전환 |
| 여러 스피커의 시차가 큼 | 모든 기기를 최신 버전으로 · 스피커 소리 맞추기 · 소스 기기 원음은 음소거 |
| 스피커 소리 맞추기가 시험음을 못 들음 | 스피커를 폰 옆 같은 거리에 · 볼륨 올리기 · 조용한 곳 · 소스 폰 마이크 권한 · 모든 기기 최신 버전 |
| Windows 자동 업데이트 실패 | EXE를 쓰기 가능한 사용자 폴더(다운로드/문서 등)로 옮긴 뒤 다시 시도 |

## 7. 기술 정보

- 오디오: PCM 16-bit 48kHz (모드 A 스테레오, 마이크 모노), 5ms 프레임, 공통 재생 대기 자동(측정 기반) 또는 40–2000ms + 스피커 소리 맞추기 보정 + 기기별 추가 지연 0–300ms
- 동기화: NTP식 연속 시계 보정 + 드리프트 추적 + Android AudioTimestamp / Windows WASAPI 장치 재생 위치 기반 예약 재생
- 전송 규약: [`PROTOCOL.md`](PROTOCOL.md) 참고 (Opus 코덱은 프로토콜에 예약됨, v1은 PCM)
- APK는 사이드로딩용 공유 디버그 키로 서명되어 있습니다. 앱 스토어 배포 시 별도 서명 필요.
- 오디오는 LAN 안에서 **암호화 없이** 전송됩니다. 신뢰할 수 있는 네트워크(집/개인 공유기)에서 사용하세요.
