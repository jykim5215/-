# 스토어 그래픽 규격

Play가 요구하는 형식입니다. 2026-09-13에 공식 문서로 확인했습니다.

| 파일 | 규격 |
|---|---|
| `icon-512.png` | 512×512, **32비트 PNG(알파 채널 포함)**, 1MB 이하 |
| `feature-1024x500.png` | 1024×500, **24비트 PNG(투명도 없음)** 또는 JPEG |
| 휴대폰 스크린샷 | **최소 2장**(3~8장 권장), 최소변 320px 이상, 최대변 3,840px 이하, 16:9 또는 9:16 |

**두 파일 모두 한 번 규격을 위반한 적이 있습니다.** 아이콘은 알파 채널이 없는 24비트
RGB였고, 그래픽 이미지는 드라이브 업로드 용량에 맞추려고 색을 줄이는 바람에 8비트
팔레트 PNG가 돼 있었습니다. 지금 이 폴더의 파일은 고친 것입니다.

형식을 바꿀 일이 있으면 저장하기 전에 확인하세요:

```bash
python3 -c "
from PIL import Image
for p in ('icon-512.png','feature-1024x500.png'):
    im = Image.open(p); print(p, im.size, im.mode)
"
# icon-512.png (512, 512) RGBA   ← 32비트, 알파 있음
# feature-1024x500.png (1024, 500) RGB   ← 24비트, 투명도 없음
```

드라이브의 `03_graphics/` 폴더에는 이 두 파일이 없습니다. 커넥터가 45KB PNG를
온전히 올리지 못해(11,940바이트가 2,627바이트로 잘려 올라갔습니다) 대신 안내 문서를
두었습니다. 이 폴더의 파일을 직접 끌어다 놓으시면 됩니다.
