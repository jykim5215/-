# 글벗 (Geulbeot)

안드로이드에서 한글 문서(`.hwp`)와 한글 표준 문서(`.hwpx`)를 **열고, 고치고, 저장하는** 앱입니다.
휴대폰과 태블릿 모두에서 쓸 수 있고, 문서는 기기 밖으로 나가지 않습니다.

## 어떻게 만들어졌나

```
geulbeot/
├── core-hwp/     순수 Kotlin/JVM. 안드로이드 의존성 0. 문서 형식 엔진.
└── app/          Jetpack Compose 안드로이드 앱.
```

`core-hwp`를 안드로이드에서 떼어낸 이유는 단순합니다. **에뮬레이터 없이 단위 테스트로 검증하기 위해서**입니다.
파일 형식을 다루는 코드는 눈으로 봐서는 맞는지 알 수 없고, 한 바이트만 틀려도 문서가 열리지 않습니다.

```
./gradlew :core-hwp:test     # 형식 엔진 테스트 (안드로이드 SDK 없이 실행됩니다)
./gradlew :app:assembleDebug # 앱 빌드 (안드로이드 SDK 필요)
./gradlew packageDistribution # 배포용 소스 압축 만들기
```

### 형식에 대해 알아야 할 것

**`.hwp` (한글 5.0)** 는 복합 문서(CFB) 안에 압축된 레코드 스트림이 들어 있는 바이너리 형식입니다.
공개된 사양이 있지만 전부를 설명하지는 않습니다. 그래서 이 앱은 **보존 정책**을 씁니다:

- 해석하지 못한 레코드는 **버리지 않고 원본 그대로** 다시 씁니다.
- 사용자가 건드리지 않은 문단은 **원본 레코드를 바이트 단위로 그대로** 다시 씁니다.

즉 이 앱에서 문서를 열었다 저장해도, 이 앱이 모르는 부분이 조용히 사라지지 않습니다.

**`.hwpx` (OWPML)** 는 ZIP + XML로 된 국가표준(KS X 6101)입니다. 사양에 빈 곳이 없어 이 앱이 가장
정확하게 쓸 수 있는 형식이고, 그래서 **새 문서의 기본 저장 형식**입니다. 한글 2014 이후에서 그대로 열립니다.

### 할 수 없는 것

정직하게 적어 둡니다.

- **암호가 설정된 문서, 배포용 문서, DRM 문서는 열지 않습니다.** 우회를 시도하지 않고, 한글 PC판에서
  보호를 푼 뒤 다시 열어 달라고 안내합니다.
- **새 문서를 `.hwp`로 저장하는 경로**는 구역 정의(`secd`) 레코드를 직접 만들어야 하는 유일한 지점이라
  이 프로젝트에서 확신도가 가장 낮습니다. 새 문서는 `.hwpx`를 권합니다. (`.hwp`로 열었던 문서를
  `.hwp`로 저장하는 것은 원본 구역 정의를 그대로 쓰므로 해당되지 않습니다.)
- **수식, 차트, OLE 개체, 글상자 같은 개체**는 내용을 해석하지 않습니다. 자리만 표시하고, 저장할 때는
  원본을 그대로 보존합니다.
- 화면 편집은 문단 단위 텍스트 필드로 되어 있어 **쪽 나눔이 화면에 그대로 보이지는 않습니다.**
  쪽 나눔과 여백은 PDF 내보내기와 인쇄에서 정확히 적용됩니다.
- 글꼴은 기기에 있는 것으로 대체됩니다. 휴대폰에 함초롬바탕이 없으므로, 명조 계열은 세리프로,
  고딕 계열은 산세리프로 그립니다.

## 개인정보와 보안

- **문서는 기기 밖으로 나가지 않습니다.** 네트워크는 GitHub 공개 릴리즈 확인 한 가지에만 씁니다.
- **저장소 권한을 요구하지 않습니다.** SAF(Storage Access Framework)로 사용자가 고른 파일에만 접근합니다.
- **문서에 기기 정보를 넣지 않습니다.** 지은이·제목은 사용자가 직접 적은 것만 저장되고, 저장 파일의
  타임스탬프는 고정값입니다.
- **토큰이나 자격 증명이 코드에 없습니다.** 공개 API만 씁니다.
- 자세한 점검 내역은 [SECURITY.md](SECURITY.md)에 있습니다.

## 빌드

1. Android Studio로 `geulbeot/` 폴더를 엽니다. (Android SDK 35, JDK 17 이상)
2. 첫 실행 시 Android Studio가 `local.properties`를 만들고, 그때부터 `:app` 모듈이 빌드 대상에 들어옵니다.
3. `Run` 을 누르면 기기나 에뮬레이터에 설치됩니다.

서명해서 배포하려면 `geulbeot/keystore.properties` 를 만들고 아래를 채웁니다. 이 파일과 키스토어는
`.gitignore` 에 들어 있고, `packageDistribution` 작업도 명시적으로 제외합니다.

```properties
storeFile=release.jks
storePassword=...
keyAlias=...
keyPassword=...
```
