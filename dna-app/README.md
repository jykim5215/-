# DNA 편집실 — 디지스트신문 DNA 편집 지원 앱

기자 한 명이 기사 기획부터 카드뉴스 발행까지 6단계 워크플로우를 한 곳에서 진행하는 로컬 우선(local-first) 앱.

```
[1] 브레인스토밍 → [2] 취재 이메일 → [3] 자료 수집 → [4] 분석·제언 → [5] 기사 초안 → [6] 카드뉴스
```

## 현재 상태 — 마일스톤 1: UI 스타일 시안

`design-mockups/`에 서로 다른 세 방향의 시안이 있습니다. 세 시안 모두 동일한 정보 구조
(좌: 6단계 내비게이션 / 중앙: 작업 영역 / 우: 자료·검증·피드백 패널)를 공유하며,
단계 5(기사 초안 에디터) 화면을 기준으로 제작했습니다.

| 시안 | 파일 | 방향 |
|---|---|---|
| A — 지면 데스크 | `style-a-newsroom.html` | 신문 지면 감각. 종이 흰색, 명조 헤드라인, 교열 빨강 |
| B — 야간 데스크 | `style-b-nightdesk.html` | 다크 모드 집중 환경. 흑연 배경, 형광펜 노랑 강조 |

각 파일은 브라우저에서 바로 열립니다 (의존성 없음).

### UX 설계 결정 (사용자 시뮬레이션 기반)

- **페이지 분리 대신 단일 3분할 레이아웃**: 마감 전날 밤의 기자는 초안 ↔ 녹취 ↔ 검사 결과를
  수십 번 오간다. 단계마다 페이지를 바꾸는 위저드 대신, 좌측 레일에서 단계를 전환하고
  중앙+우측 패널 구조는 유지하는 형태를 채택. 자료 패널은 모든 단계(2~6)에서 동일하게 재사용 — 중복 제거.
- **검증 결과는 인라인 + 요약 이중 표기**: 인용 오류는 본문에서 빨간 하이라이트로,
  우측 패널에서 통과율로 한눈에 확인.
- **피드백 위젯(별점+태그)은 우측 패널 상주**: 저장 시 모달로 가로막지 않고, 원클릭으로 기록
  (학습 데이터 파이프라인 Layer 1의 마찰 최소화 요건).

## 대기 중인 결정

1. **UI 스타일 선택** (A / B / C, 또는 조합)
2. **패키징 방식** — Electron(권장: Node 단일 런타임으로 pptx XML 편집·SQLite·벡터검색까지 처리) vs Tauri+Python 사이드카 vs PWA
3. **템플릿 pptx 입수** — `인스타그램_카드뉴스_2025개편.pptx`, `조정부_카드뉴스_2025양식.pptx`가
   아직 저장소에 없음. 단계 6 구현 전 필요.
