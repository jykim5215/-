# DNA 취재 이메일 공식 형식 (하드코딩 규칙)

## 제목
- 반드시 `[디지스트신문 DNA]`로 시작한다.
- 이어서 용건을 명확히 쓴다. 예: `[디지스트신문 DNA] 조정부 승격 관련 서면 인터뷰 요청`
- 용건은 "~~ 요청", "~~ 관련" 형태를 권장한다.

## 본문 구성 (순서 고정)
1. 인사 + 자기소개: **직함→이름 순**. 예: "안녕하세요, 디지스트신문 DNA 기자 ○○○입니다."
2. (수신자가 매체를 모를 수 있는 경우) 매체 소개 한두 문장:
   "디지스트신문 DNA는 DGIST의 학생 자치 언론기구로, 학내 소식을 취재·보도하고 있습니다."
3. 본문: 무엇을 왜 요청하는지 명확히. 기사 주제, 요청 내용(인터뷰/자료), 희망 일정, 소요 시간.
4. 질문지가 있으면 첨부 안내 문장.
5. 마무리 인사 + 이메일 명함/서명:
   ```
   디지스트신문 DNA {직함} {이름} 드림
   {이메일} | dgistdna.com
   ```

## 톤
- 정중하고 명확하게. 과도한 겸양·장황함 금지.
- 답장 기한을 부드럽게 명시한다 (예: "○월 ○일까지 회신 주시면 감사하겠습니다").
