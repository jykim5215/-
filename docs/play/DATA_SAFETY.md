# 데이터 보안(Data safety) 양식 답안 — 단어장 (VocaCard)

Play Console → 정책 → 앱 콘텐츠 → **데이터 보안** 에 그대로 옮겨 적을 답.
**정확하지 않게 답하면 나중에 앱이 내려갈 수 있으므로**, 왜 그렇게 답하는지
근거를 함께 적어 둔다.

---

## 1단계 — 데이터 수집 및 공유

> **앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요?**
> → **예**

"아니요" 가 아니라 **"예"** 인 이유를 반드시 이해할 것.

앱은 사용자 정보를 서버에 모으지 않는다. 하지만 **단어 추가 화면에서 입력한
영어 단어가 제3자 사전 서비스(`api.dictionaryapi.dev`)로 전송**된다.
Play 의 정의상 "앱에서 제3자로 데이터를 전송" 하면 **공유(shared)** 에 해당한다.
이 통신이 존재하는 한 "수집·공유 없음" 이라고 답하면 사실과 다르다.

> 이 통신을 없애고 싶다면: `Suggester` 에서 `DictionaryApi` 호출을 제거하거나,
> `SettingsStore.onlineSuggest` 기본값을 `false` 로 바꾸고 기본 꺼짐으로 출시하면
> 된다. 그래도 내장 1,222단어 사전 추천은 그대로 동작한다.
> 그렇게 바꾸면 아래 답을 "수집·공유 없음" 으로 단순화할 수 있다.

---

## 2단계 — 데이터 유형 선택

체크할 항목은 **하나뿐**이다.

### ☑ 앱 활동 → 기타 사용자 생성 콘텐츠 (App activity → Other user-generated content)

사용자가 검색창에 입력한 **영어 단어 한 개**가 여기에 해당한다.

| 질문 | 답 | 근거 |
|---|---|---|
| 수집됨(Collected) | **아니요** | 개발자 서버가 없다. 앱이 사전 서비스를 직접 호출하고, 개발자는 그 값을 받지도 저장하지도 않는다 |
| 공유됨(Shared) | **예** | 제3자(dictionaryapi.dev)로 전송된다 |
| 처리 방식 | **일시적으로 처리됨** | 응답을 받아 화면에 뿌리는 즉시 끝난다. 전송한 값을 앱이 따로 보관하지 않는다 |
| 필수 여부 | **선택 사항** | 설정 → 온라인 사전 추천 을 끄면 전송이 완전히 중단되고, 앱은 그대로 동작한다 |
| 목적 | **앱 기능** | 뜻·예문 후보 제공 |
| 사용자 계정과 연결됨 | **아니요** | 계정이 없다. 인증 토큰 없이 익명 호출한다 |

### 체크하지 않을 항목 — 아래는 전부 **해당 없음**

- 위치, 개인 정보(이름·이메일·주소·전화번호), 금융 정보
- 연락처, 캘린더, 사진·동영상, 오디오 파일, 파일·문서
- 메시지, 건강·피트니스
- **앱 활동 → 앱 상호작용 / 인앱 검색 기록**
  (검색 기록을 저장하지 않는다. 저장하는 것은 사용자가 **직접 저장 버튼을 눌러
  자기 단어장에 넣은** 항목뿐이고, 그건 기기 밖으로 나가지 않는다)
- **기기 또는 다른 ID** (광고 ID·기기 ID 를 읽지 않는다)
- 크래시 로그, 진단 정보 (분석 SDK 를 넣지 않았다)

## 3단계 — 보안 관행

| 질문 | 답 | 근거 |
|---|---|---|
| 전송 중 데이터가 암호화되나요? | **예** | 모든 통신이 HTTPS 다. 매니페스트에 `usesCleartextTraffic="false"` 로 평문 통신을 아예 막아 두었다 |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** | 앱 안 **설정 → 학습 기록 초기화** 로 즉시 전부 삭제된다. 앱 삭제로도 사라진다. 서버에 보관된 것이 없으므로 별도 삭제 요청 창구가 필요 없다 |
| Play Families 정책 준수 | 해당 없음 | 아동 대상 앱이 아니다 |
| 독립적인 보안 검토를 받았나요? | **아니요** | 받은 적 없다. "예" 로 답하려면 실제 외부 감사 증빙이 필요하다 |

## 참고 — 데이터가 실제로 어디에 있는지

| 데이터 | 위치 | 외부 전송 |
|---|---|---|
| 내 단어장(단어·뜻·예문·메모) | 기기 내부 SQLite | 없음 |
| 학습 상태(정답/오답, 복습 예정일) | 기기 내부 SQLite | 없음 |
| 아카이브 진행률·암기 표시 | 기기 내부 SQLite | 없음 |
| 앱 설정 | 기기 내부 DataStore | 없음 |
| **검색창에 입력한 영어 단어** | 보관하지 않음 | **dictionaryapi.dev 로 전송** |
| 발음용 텍스트 | 보관하지 않음 | 기기 내 TTS 엔진으로만 전달 |

Android 자동 백업이 켜져 있으면 위 기기 내부 데이터가 **사용자 본인의**
Google 계정 백업에 포함될 수 있다. 이는 OS 기능이며 개발자는 접근할 수 없다.
(데이터 보안 양식에서 별도로 신고할 항목은 아니다.)
