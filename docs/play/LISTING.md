# 스토어 등록정보 문안 — 단어장 (VocaCard)

Play Console → 스토어 설정 / 기본 스토어 등록정보 에 그대로 붙여넣을 수 있게
글자 수까지 맞춰 두었다. 마음에 안 드는 표현은 자유롭게 고쳐도 된다.

---

## 앱 이름 (30자 이내)

```
단어장 - 30일 영단어 암기
```
(15자)

> 대안: `단어장: 몰랐던 단어만 모아서` (16자)

## 간단한 설명 (80자 이내)

```
몰랐던 단어만 자동으로 모아 잊을 때쯤 다시 보여 주는 영단어 암기장
```
(38자)

## 자세한 설명 (4,000자 이내)

```
30일치 영단어를 담아 두고, 내가 몰랐던 단어만 골라 반복해서 보여 주는 단어장입니다.

■ 몰랐던 단어는 알아서 모입니다
학습 중 "몰라요"를 누른 단어가 자동으로 내 단어장에 쌓입니다.
따로 정리하거나 옮겨 적을 필요가 없습니다.

■ 잊어버릴 때쯤 다시 나타납니다
틀린 단어는 10분 뒤에 바로 한 번 더, 맞을수록 1일 → 3일 → 7일 → 16일 → 35일로
간격을 벌려 가며 다시 보여 줍니다. 오래 기억에 남도록 설계된 간격 반복 방식입니다.

■ 네 가지 학습 방법
학습을 시작할 때마다 원하는 방식을 고릅니다.
· 암기 카드 — 카드를 뒤집으며 뜻 확인, 좌우로 밀어 아는지 표시
· 뜻 → 단어 — 뜻을 보고 영단어 떠올리기
· 4지선다 — 보기 중에서 고르기
· 스펠링 — 직접 철자 입력

■ 30일 아카이브
Day 1부터 Day 30까지 1,222개 단어가 들어 있습니다.
뜻 가리기를 켜면 목록 자체가 셀프 테스트가 됩니다.

■ 단어를 직접 추가할 때
영어를 입력하면 뜻 후보가 뜹니다. 다의어는 뜻마다 따로 나오니 필요한 것만
골라 담을 수 있습니다. 예문도 함께 추천되고, 직접 고쳐 쓸 수 있습니다.

■ 발음 듣기
학습 카드와 단어 상세에서 발음을 들을 수 있습니다.
암기 카드는 단어가 나올 때 자동으로 읽어 줍니다(설정에서 끌 수 있습니다).

■ 외운 단어가 쌓이는 것을 봅니다
"완전히 아는 단어"가 몇 개인지 화면 맨 위에 크게 보여 줍니다.
그 숫자를 누르면 외운 단어들이 통 안에 쌓여 있습니다.
기기를 기울이면 그쪽으로 굴러가고, 흔들면 튀어 오르고, 손가락으로 집어 던질 수 있습니다.

■ 계정도, 광고도 없습니다
로그인이 없습니다. 광고와 분석 도구를 넣지 않았습니다.
학습 기록은 전부 기기 안에만 저장되며 어디로도 전송되지 않습니다.
인터넷 없이도 모든 기능이 동작합니다(사전 추천만 온라인일 때 더 풍부해집니다).
```

## 스크린샷 — 무엇을 찍을지

Play 는 휴대전화 스크린샷을 **최소 2장** 요구한다(8장까지). 아래 순서를 권한다.

1. **홈** — "완전히 아는 단어" 숫자와 쌓인 단어가 보이는 화면
2. **암기 카드** — 단어 면 (스와이프 안내가 보이는 상태)
3. **쌓기 보기** — 단어가 통에 쌓여 있는 화면
4. **단어 추가** — 뜻 후보가 여러 개 떠 있는 화면 (다의어 예: `cover`)
5. **아카이브** — Day 1~30 그리드
6. **내 단어** — 복습 예정 목록

찍는 법:

```bash
scripts/capture-screenshots.sh          # USB 연결된 기기에서 순서대로 캡처
```

> 스크린샷은 **실제 앱 화면이어야 한다.** 합성하거나 목업을 올리면
> 오해를 부르는 정보로 반려될 수 있다.
