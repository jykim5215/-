# Google Play 출시 체크리스트 — 단어장 (VocaCard)

`scripts/build-bundle.sh` 로 만든 `.aab` 를 올리기 전후로 확인할 것들.
**[코드]** 표시는 이미 코드에 반영되어 있고, **[해야 함]** 은 사람이 직접 해야 하는 일이다.

---

## 0. 먼저 알아야 할 것 — 자체 업데이트는 Play 에 못 올린다

Google Play 는 **앱이 스스로 APK 를 내려받아 설치하는 것을 금지**한다
(Device and Network Abuse 정책). `REQUEST_INSTALL_PACKAGES` 권한도
앱스토어·기기 관리 앱이 아니면 승인되지 않는다.

이 앱에는 GitHub 릴리즈 기반 자체 업데이트가 들어 있었기 때문에,
**배포 채널을 둘로 나눴다.**

| 플레이버 | Gradle 태스크 | 자체 업데이트 | `REQUEST_INSTALL_PACKAGES` |
|---|---|---|---|
| `github` | `assembleGithubRelease` | 있음 | 있음 |
| `play` | `bundlePlayRelease` | **없음** | **없음**(매니페스트에서 제거) |

Play 에는 **반드시 `play` 플레이버 번들**을 올린다. `scripts/build-bundle.sh` 가
그 태스크를 쓴다. **[코드]**

## 1. 빌드

- **[코드]** `applicationId` = `com.vocacard.app` — 한 번 정하면 영원히 못 바꾼다
- **[코드]** `minSdk 26` / `targetSdk 35` (2025년 이후 신규 등록 요건 충족)
- **[코드]** `versionCode` / `versionName` 은 루트 `version.json` 에서 나온다
- **[해야 함]** 업로드할 때마다 `version.json` 의 **`versionCode` 를 반드시 올린다.**
  Play 는 같은 versionCode 를 두 번 받지 않는다
- **[코드]** 릴리즈 빌드는 난독화(R8)를 **끈 상태**다.
  이유: 이 앱은 실기 테스트를 거치지 않았고, R8 오설정은 런타임에만 터진다.
  규칙(`proguard-rules.pro`)은 준비되어 있으니, 실기에서 충분히 검증한 뒤
  `isMinifyEnabled = true` 로 바꾸면 용량이 더 줄어든다
- **[코드]** 언어 분할 끔 — 기기 언어와 무관하게 한국어 문구가 항상 포함된다

## 2. 서명

- **[해야 함]** Play Console 최초 설정에서 **Play 앱 서명**을 켠다(권장 기본값)
- **[해야 함]** 우리가 만든 `vocacard-release.jks` 를 **업로드 키**로 쓴다
  - RSA 4096 / 별칭 `vocacard` / 2053년까지 유효
  - **이 파일을 잃어버리면 업데이트를 올릴 수 없다.** 반드시 별도 백업
- **[해야 함]** GitHub 릴리즈용으로 이미 이 키를 쓰고 있다면 그대로 쓰면 된다

## 11. 업로드

```bash
# 서명 키를 환경 변수로 주고 번들 빌드
VOCA_KEYSTORE=~/vocacard-release.jks \
VOCA_KEYSTORE_PASSWORD=... VOCA_KEY_ALIAS=vocacard VOCA_KEY_PASSWORD=... \
scripts/build-bundle.sh
```

1. Play Console → 앱 만들기
2. **내부 테스트** 트랙에 먼저 올려 본인 기기에서 설치·확인 (권장)
3. 위 4~9 항목을 모두 채운다(하나라도 비면 프로덕션 출시 버튼이 안 열린다)
4. 프로덕션 → 새 버전 → `.aab` 업로드 → 검토 제출

첫 심사는 보통 며칠 걸린다. 신규 개발자 계정은 추가 확인이 붙을 수 있다.

## 12. 출시 후

- `version.json` 의 `version` + `versionCode` 를 올리고 다시 빌드하면 새 버전이 된다
- GitHub 릴리즈(`github` 플레이버)와 Play(`play` 플레이버)는 **같은 코드, 다른 기능 범위**다.
  Play 쪽에는 자체 업데이트가 없다는 점만 기억하면 된다
