# 🎸 기타 탭 스튜디오 (Guitar Tab Studio)

기타 연주 오디오를 분석해 **타브(TAB) 악보**로 만들고, 여러 곡을 묶어
**표지 + 목차가 있는 악보집 PDF**로 내보내는 앱.

- **설치 불필요 · 서버 불필요** — `index.html` 을 브라우저로 열면 끝. 인터넷 없이도 동작합니다.
- **의존성 0개** — CDN도, npm 패키지도 쓰지 않습니다. FFT·PDF 생성기·신디사이저까지 전부 자체 구현.
- **데이터는 기기 밖으로 나가지 않습니다** — 오디오는 브라우저 안에서만 처리되고, 악보는 이 기기에만 저장됩니다.

---

## 빠른 시작

```bash
# 1) 바로가기 만들기 (권장)
bash tools/make-shortcut.sh                                   # macOS / 리눅스
powershell -ExecutionPolicy Bypass -File tools\make-shortcut.ps1   # 윈도우

# 2) 또는 그냥 파일을 더블클릭
#    index.html
```

> 탭 오디오 캡처 기능은 **Chrome / Edge** 에서 가장 잘 동작합니다.

## 쓰는 법 — 4단계

### 01. 소리 가져오기
세 가지 방법이 있고, 어느 쪽이든 결과는 같습니다.

| 방법 | 설명 |
|---|---|
| **유튜브 탭 캡처** (권장) | 다른 탭에서 기타 영상을 재생 → `＋ 소리 가져오기` → 그 탭을 선택하고 **“탭 오디오도 공유”를 체크** → 영상을 처음부터 재생 → 정지. 화면 영상은 쓰지 않고 소리만 녹음합니다. |
| **오디오 파일** | mp3 · m4a · wav · ogg · mp4 · webm 을 창에 끌어다 놓으면 됩니다. |
| **yt-dlp 헬퍼** | `bash tools/fetch-youtube.sh "<URL>"` 로 오디오만 받아서 위 방법으로 넣습니다. (yt-dlp 가 설치돼 있어야 함) |

### 02. 분석
튜닝 · 카포 · 동시에 잡을 음 수(단선율 1 ~ 스트로크 6) · 감도를 고르고 실행합니다.
4분짜리 곡이면 보통 10–40초. 분석은 이 기기의 CPU만 씁니다.

엔진이 하는 일: 스펙트럼 화이트닝 → 하모닉 살리언스로 다중 음고 추출 → 온셋 검출 →
노트 트래킹 → 온셋 엔벨로프 자기상관으로 템포·비트 그리드 → 크로마로 조성(Krumhansl)과
코드 추정 → **DP(비터비)로 지판 운지 최적 배정**.

### 03. 다듬기
자동 채보는 완벽할 수 없습니다. 그래서 **엔진 80% + 사람이 고치는 편집기 20%** 로 설계했습니다.
신뢰도가 낮은 음은 **흐린 숫자**로 표시되니 거기부터 확인하세요.

| 조작 | |
|---|---|
| 클릭 | 음 선택 (선택하면 소리로 확인) |
| `↑` `↓` | 줄 이동 (음 높이는 유지) |
| `←` `→` | 프렛 ±1 / `Shift`와 함께 누르면 칸 이동 |
| `0`–`9` | 프렛 직접 입력 (두 자리도 빠르게 연타) |
| `Del` | 삭제 |
| `Space` | 재생 / 정지 |

재생은 Karplus-Strong 발현음 합성이라 사운드폰트 없이도 소리가 납니다.
아래 재생바에서 루프 · 0.35×~1.25× 속도 · 메트로놈을 켤 수 있습니다.

### 04. PDF 내보내기
- **이 곡 · 타브 악보 PDF** — 제목/튜닝/카포/BPM 머리글, 코드명, 주법 기호, 페이지 번호가 들어간 인쇄용 벡터 악보.
- **악보집 PDF** — 왼쪽 목록에서 곡을 체크하고 `악보집 PDF 엮기`. **표지 → 목차(쪽번호 포함) → 각 곡 악보** 순으로 한 파일로 묶입니다.
- 그 밖에 ASCII 타브 `.txt`, `.mid`, 프로젝트 `.json` 도 내보낼 수 있습니다.

용지(A4/Letter), 한 줄에 넣을 마디 수, 코드명·주법 표시 여부는 내보내기 창에서 조절합니다.

## AI 다듬기 (선택)

설정에 본인의 Anthropic API 키를 넣으면, 채보 결과를 정리해줍니다.
구간 이름(Intro/Verse/Chorus) 붙이기, 진행상 어색한 코드 정정, 연습 팁, 제목 후보.

- **오디오는 보내지 않습니다.** 마디 수·음표 밀도·코드 진행·BPM·조성 같은 요약만 보냅니다.
- 키는 이 기기의 브라우저 저장소에만 있고, 앱 코드에는 어떤 키도 들어있지 않습니다.
- 키가 없으면 이 기능만 꺼지고 나머지는 전부 그대로 동작합니다.

## 저작권에 대해

이 앱은 **채보 도구**입니다. 곡 데이터베이스나 기성 악보를 담고 있지 않고,
사용자가 직접 넣은 오디오를 분석할 뿐입니다.

만들어진 채보는 **본인 연습·학습 용도**로 쓰세요. 원곡은 저작권이 있으므로,
채보 결과를 공개 배포하거나 판매하면 문제가 될 수 있습니다.

## 알려진 한계

- 다성(여러 음이 동시에 울리는) 채보는 원리상 완벽하지 않습니다. 특히 드럼·보컬이 섞인 음원은 정확도가 떨어집니다. 기타 소리가 뚜렷한 구간일수록 잘 나옵니다.
- 박자가 흔들리는 연주는 마디 나눔이 어긋날 수 있습니다. BPM을 직접 고쳐 넣으면 다시 정렬됩니다.
- 탭 오디오 캡처는 브라우저와 OS에 따라 막힐 수 있습니다. 그때는 오디오 파일로 넣으세요.
- 한 번에 15분까지 처리합니다. 더 긴 곡은 구간을 나눠 넣으세요.
