12대 분류를 직접 조정합니다. 합계는 자동으로 1,000으로 정규화되고, 결과와 기여도가 즉시 갱신됩니다.

합계 1,000.0 → 1,000으로 정규화
파일은 서버로 전송되지 않습니다. 카드 이용내역은 이 브라우저 안에서만 열리고 분석됩니다. 서버로 보내는 것은 집계된 12개 분류 가중치 숫자뿐이며, 가맹점명·결제일자·금액은 전송되지 않습니다.

신한·KB·삼성·롯데 카드의 이용내역 엑셀(가맹점명·업종·금액·일자 포함)을 지원합니다. 카드 승인은 가맹점 단위라 12대 분류까지만 자동으로 나눕니다. 458개 품목 단위로는 쪼갤 수 없습니다.
